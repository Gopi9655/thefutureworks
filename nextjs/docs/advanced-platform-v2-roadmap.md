# thefutureworks Advanced Platform v2 Roadmap
Status: high-fidelity concept/prototype, not the official thefutureworks website.
## Phase 0 — Baseline, safety, and roadmap
Goals:
- Preserve v1 on main.
- Build v2 only on advanced-platform-v2.
- Confirm current routes, build health, dependency state, and screenshot QA.
- Define the production-style platform architecture before implementation.
Checks:
- npm run typecheck
- npm run build
- Playwright screenshot QA
- Route smoke checks
- Responsive and horizontal-overflow checks
Architecture targets:
- Next.js App Router
- TypeScript
- Tailwind
- React Three Fiber / Three.js
- Data-driven job records
- Candidate apply flow
- Employer request-staff flow
- Admin/dashboard concept
- Accessibility and responsive QA
Design targets:
- Modern 2026 recruitment platform
- Green for jobs, candidates, opportunity
- Blue for employers, Coventry University, trust
- White/off-white for clarity and official platform feel
- Premium depth without dark cyber/SaaS styling
- 3D recruitment-matching visuals that support the user journey
Phase 0 deliverables:
- Branch created safely from main
- Roadmap committed
- v1 baseline verified before v2 work starts
- No implementation changes yet
