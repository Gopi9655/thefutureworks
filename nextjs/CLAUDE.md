# CLAUDE.md

Claude Code-specific rules for this repository. Read `AGENTS.md` first for the shared protocol.

## Where Claude Code is best used

- UI, visual design, CSS, animation, layout, and responsive polish.

## Workflow rules

- For **visual work, stop before commit** and ask the user to inspect `localhost` first.
- Always **report changed files and screenshots** after each change.

## Visual direction

- **Do not** create giant hero text.
- **Do not** create plain white / flat SaaS layouts.
- Colour language:
  - **Green** for candidates, jobs, opportunity.
  - **Blue** for employers, Coventry, trust.
  - **Off-white** for official clarity.
- Prefer **premium depth**: glass surfaces, 3D-style cards, and motion.
- All motion must include a **reduced-motion fallback** (`prefers-reduced-motion`).

## Reminder

- Never push visual work before local browser approval.
- Use synthetic concept data only — no real candidate data, no real CV storage.
